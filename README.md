# HR Analytics Dashboard

## Project Overview

This project is an interactive **HR Analytics Dashboard** developed using **Tableau**. The dashboard provides insights into employee demographics, departments, job roles, income, education, performance, and other HR-related information.

## Objective

The objective of this project is to analyze employee data and present meaningful HR insights through an interactive and easy-to-understand Tableau dashboard.

## Tools Used

* Tableau
* CSV Dataset

## Key Analysis

The dashboard provides analysis of:

* Employee demographics
* Department-wise employee distribution
* Job roles and positions
* Employee income and salary analysis
* Education levels
* Employee performance
* Gender distribution
* Employee location
* Hiring and termination trends

## Dashboard

The Tableau dashboard allows users to interact with the data using filters and visualizations to explore different aspects of the workforce.

## Project Files

* **Tableau/** – Contains the Tableau packaged workbook.
* **Data/** – Contains the dataset used for the analysis.
* **Screenshots/** – Contains screenshots of the completed dashboard.


## Conclusion

This dashboard demonstrates how Tableau can be used to transform HR data into interactive visualizations and support data-driven analysis of an organization's workforce.
